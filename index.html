ホワサバ スケジュール生成 (v1.2) - チャット特化マトリクス＆リアルタイム共同編集ツール

スマートフォンゲーム「ホワイトアウト・サバイバル」の同盟幹部（R5/R4）向けスケジュール支援Webアプリです。
ゲーム内のイベントをスケジュール管理し、ゲーム内でそのまま利用できるテキストを生成します。ゲーム内等幅チャット特有の制約（改行上限10回、全角16文字幅の自動折り返し、サロゲートペアによる文字幅ズレ）を精密な文字幅計算と自然折り返しで克服。さらにFirebase Cloud Firestoreを用いたリアルタイム双方向同期、RTDBによる接続端末数検知、Stripe決済連携による開発者支援機能を備えています。

役割: 企画・要件定義・UI/UX設計・フロントエンド実装・サーバーレスDB設計（単独開発）
制作時期: 2026年10月〜11月 (v1.2.0)
【技術スタック】
・フロントエンド: HTML5, CSS3, JavaScript (ES6+), Tailwind CSS
・クラウドDB / BaaS: Firebase Cloud Firestore (リアルタイム双方向同期 onSnapshot / セキュリティルール)、Firebase Realtime Database (プレゼンス機能による接続端末数リアルタイム検知)
・決済連携: Stripe Payment Link (Apple Pay / Google Pay / クレジットカード決済による開発者支援・寄付連携)
・セキュリティ・暗号化: Web Crypto API (SubtleCrypto / SHA-256 ハッシュ化によるクライアント認証)
・アルゴリズム・文字処理: Unicodeサロゲートペア・異体字対応トークナイザ、半角/全角表示幅計算、末尾スペース自動折り返しフォーマッタ
・共有 / シェア: Web Share API、クリップボードAPI (Discord用テンプレート出力)、OGP (Discord/SNS大判プレビュー最適化)
・ホスティング / CI/CD: GitHub Pages, Git / GitHub
【主な機能・課題解決】
・ゲーム内チャット制約の完全克服: 「本文改行を消費せず全角16文字幅で自然改行させる末尾スペース付与」「全角・半角・絵文字の精密な幅合わせ」により、スマホ/PC問わず崩れない表を出力
・リアルタイム双方向同期: Firebase Firestoreのリスナーにより、同盟内幹部の編集内容をリロード不要で画面へ即座に自動反映
・アクティブ接続数検知: Firebase RTDBのプレゼンス機能（.info/connected、onDisconnect）を活用し、現在アプリを開いている端末数をヘッダーにリアルタイム（🟢 接続数: N）表示
・編集中競合ガード: 自身がモーダルで編集作業中は他者の変更適用を待機させ、作業中データの不意な上書き・消失を防止
・同盟アカウント認証: アカウントID＋パスワード（SHA-256）による安全な権限分離、旧セッション自動ログアウト付きパスワード変更機能
・直感的なマトリクス操作: 8日間固定テーブル、イベントの優先度ドラッグ並べ替え、重複項目の記号統合（🔴🔵等）＆カスタマイズ
・ワンクリック共有＆Discord連携: Web Share APIやDiscord専用テンプレート生成により、幹部から同盟メンバーへのアプリ共有動線を最適化
・Stripe開発者支援: Apple Pay / Google Pay対応のセキュアな決済リンクをUI内に統合し、持続可能な個人開発体制を構築
・二重の安全性: JSONエクスポート/インポート（バックアップ・別同盟への複製）、初期テンプレート展開機能
【公開・リンク】
・公開Webサイト: Webアプリを開く
・GitHubリポジトリ: howasaba_event
AnyDetect - 画像検知＆アクションマクロ自動化デスクトップアプリ (v2.1.0)

画面上の特定エリアをリアルタイムで監視し、指定画像の出現をトリガーに「マクロ自動操作（クリック・キー入力・外部プログラム実行等）」や「マルチ通知（音声・トースト・画像添付メール）」を実行するWindowsデスクトップ自動化ツールです。
マルチモニター完全対応のリアルタイム透過オーバーレイ、PyInstallerによる単一EXE化、DWM透過制御など高度なWindowsネイティブ技術を組み込んでいます。

役割: 企画・設計・GUI実装・パッケージング（単独開発）
制作時期: 2026年8月 (v1.0) / 2026年9月 (v2.1.0 ドラッグ自動化対応)
【技術スタック】
・言語: Python 3.13
・GUI: CustomTkinter (モダンUI / ダーク・ライトテーマ対応)
・自動化・入力制御: PyAutoGUI, pyperclip (マウス・キーボード操作、マクロ自動実行)
・画像処理: OpenCV (cv2.matchTemplate), Pillow (PIL)
・音声制御: winsound (Windows PlaySound API による非同期サウンド通知)
・通知機能: Windows トースト通知 (winotify), SMTP (TLS暗号化による自動メール送信・画像添付), 検知時キャプチャ自動保存
・OS制御: Windows API (ctypes / user32 / gdi32) によるスリープ防止制御、マルチモニター仮想スクリーン制御、DWM複合透過レイヤードウィンドウ制御
・パッケージング: PyInstaller (ワンファイルEXE化)
・バージョン管理: Git, GitHub
【主な機能・特徴】
・マルチモニター全画面対応のリアルタイム透過領域指定（選択枠内だけ白半透明が抜けるスニッピング風UI）
・画像パターン相関（0.8以上）＋カラー検証による誤検知防止アルゴリズム
・検知時アクションマクロ自動実行（検知座標クリック、ドラッグ＆ドロップ、キー送信、待機、コマンド起動）
・アクション手順の直感的なドラッグ＆ドロップ並べ替え（半透明角丸カードUI）
・7種類の通知音プリセット（テスト再生・音量スライダー付き）
・検知瞬間の画面を capture_log/ へ自動保存＆ワンクリックフォルダ展開
・指定検知回数到達での自動監視終了機能
・デスクトップ上に監視領域を常時表示するクリックスルー赤点線枠オーバーレイ
・監視中のPCスリープ自動防止
